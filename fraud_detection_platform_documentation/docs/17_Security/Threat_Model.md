# Threat Model

Identify threats using a structured method such as STRIDE.

Assets:
Transactions, risk results, cases, user accounts, model artifacts, configuration and audit records.

Threats:
Credential compromise, privilege escalation, API abuse, injection, data leakage, tampering, event spoofing, model poisoning, training-data leakage and denial of service.

For each threat record likelihood, impact, mitigation and residual risk.
