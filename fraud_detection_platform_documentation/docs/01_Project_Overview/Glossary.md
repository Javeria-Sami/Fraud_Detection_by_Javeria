# Glossary

**Transaction:** A financial event submitted to the platform for analysis.

**Anomaly:** Behavior that differs materially from the learned or configured normal pattern.

**Fraud Alert:** An operational notification generated when detection conditions cross a configured threshold.

**Risk Score:** A normalized score representing the platform's calculated level of concern.

**Rule:** A deterministic condition evaluated against transaction or behavioral data.

**Case:** An investigation record containing alerts, evidence, notes, actions and resolution.

**Risk Profile:** Historical/behavioral context associated with a user, device or merchant.

**Model Drift:** Change in data or prediction behavior that can reduce model reliability.

**Idempotency:** Processing the same transaction request repeatedly without creating unintended duplicate effects.
